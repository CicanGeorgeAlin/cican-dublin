# CICAN DUBLIN ARCHIVE

**Created by CICAN GEORGE ALIN · Dublin, Ireland**

An evidence-first visual archive of Dublin's historical heritage: monuments, memorials, inscriptions, buildings, streets, archaeological remains and overlooked physical details.

## Live project
https://cicangeorgealin.github.io/cican-dublin-archive/

## Mission
Discover, verify and catalogue Dublin's historic physical environment. The founder photographs each location in person. Original photographs are preserved and may be converted into faithful black-and-white A4 line-art illustrations for a future series of Lulu.com colouring books.

## Core workflow
RESEARCH → VERIFY → REGISTER → PLAN FIELDWORK → FOUNDER PHOTOGRAPHS → ARCHIVE ORIGINAL → CREATE LINE ART → QUALITY CONTROL → WEBSITE → BOOK → PUBLISH.

## Integrity rules
- Every discovery receives one unique archive ID.
- Every historical claim must have a source.
- Research leads and verified records are kept separate.
- Never invent coordinates, object details, images or publication URLs.
- Photography is marked complete only after founder confirmation.
- Preserve original photographs separately from derivative artwork.
- Check duplicates before creating records.
- Respect access, safety, copyright and photography restrictions.

## Repository structure
- `data/objects.json` — master object catalogue.
- `data/districts.json` — geographic research zones.
- `data/categories.json` — discovery taxonomy.
- `research/` — source-based investigation.
- `routes/` — fieldwork plans.
- `photos/originals/` — founder's original photographs.
- `line-art/` — approved illustrations.
- `books/` — publication source files and metadata.
- `documentation/` — project standards.

## Current state
The landing page and foundational data files are being established. The object catalogue starts empty deliberately: no object is presented as a verified archive record until its evidence has been checked and its record approved.
