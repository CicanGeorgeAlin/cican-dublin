## Host building — DUB-BLD-0087

NIAH registration 50110448 identifies 17 Earlsfort Terrace as a terraced two-bay, three-storey house over basement, built circa 1880 as one of a pair. The detailed register description records a red-brick façade with carved brick eaves and stringcourses, decorative terracotta plaques, carved timber oriel window, stained-glass fanlight, granite steps, cast-iron bootscrape, cast-iron balustrade, matching gate, basement railings and a coal-hole cover set in a granite slab to the front pavement. The house is now in office use.

Official source: https://www.buildingsofireland.ie/buildings-search/building/50110448/17-earlsfort-terrace-dublin-2-dublin
