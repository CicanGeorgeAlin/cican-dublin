## Match notes and limitations

- **Henry Grattan Monument:** exact subject match; a tree partly obscures the statue. Retained as a useful reference, not a substitute for a clearer founder photograph.
- **Thomas Davis Monument:** the Geograph file identifies the statue and its depicted-place coordinates. Its coordinates are approximately 15 metres from the catalogue pin; no catalogue coordinate was changed.
- **George Salmon Statue:** the Commons file title and category identify George Salmon, while its description field incorrectly says Lecky. The visible white-marble seated figure is consistent with NIAH record 50020521, which describes the George Salmon statue as a seated white-marble figure. The discrepancy is disclosed in the image metadata.
- **Famine Memorial:** the photograph and depicted-object coordinates match the Custom House Quay memorial, within approximately 4 metres of the catalogue pin.
- **City Hall:** exact building subject match; wide exterior context photograph.
- **Nassau Street post box:** the file caption identifies Nassau Street and the photograph shows the double-aperture P&T pillar box and Áth Cliath lettering matching the catalogue record.

## Acceptance standard

1. Prefer exact subject photographs over nearby street or district context.
2. Check the Commons file page, not just search snippets.
3. Record creator, capture date when available, source page, direct image URL, licence, licence URL, attribution and image role.
4. Link every reference image to a registered `IMAGE_REFERENCE` source record.
5. Use `OBJECT_PHOTOGRAPH` only when the depicted object matches the catalogue entry; use `STREET_CONTEXT` for a surrounding street or setting.
6. Never convert a third-party reference image into a founder original.
7. Do not alter catalogue coordinates based on camera location metadata.
8. Preserve uncertainty and contradictory metadata in the record notes.
