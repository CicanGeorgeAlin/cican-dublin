# Visual Discovery Batch 003 — Clontarf reference photographs

**Date:** 26 October 2026  
**Project:** CICAN DUBLIN  
**Method:** Wikimedia Commons file-page inspection, image review, creator/licence/attribution recording, and comparison with catalogue descriptions and published image coordinates.

## Outcome

- Added first reference images to seven previously image-less catalogue records.

- Added eight image records in total.
- Updated visual inventory: **58 third-party reference photographs across 53 catalogue locations**.

All additions remain third-party reference images. None changes founder photography status, field verification, line-art status or publication status.

## Quality and integrity checks

- Every new image points to an existing catalogue record.
- Every image has a unique source ID.
- Every image includes an image URL, source URL, photographer, date, licence, licence URL, attribution, role and location note.
- Exact-object photographs are distinguished from contextual or comparison references.
- DUB-BLD-0076 is explicitly distinguished from the separate Castle Avenue church ruin records.
- DUB-BLD-0054 remains a comparison image; the exact identification of the cast-iron structure is not asserted as settled.
- No founder photography or line-art status was changed.

## Remaining work

The objective remains one relevant reference photograph for every catalogue point. The 142 records without images remain in the visual-discovery backlog. Continue with exact-object matches first, then carefully labelled street-context images where the photograph genuinely helps a visitor recognise the surrounding place. Do not use generic Dublin photographs, unrelated nearby objects, copyrighted images without permission, or generated imagery as documentary evidence.
