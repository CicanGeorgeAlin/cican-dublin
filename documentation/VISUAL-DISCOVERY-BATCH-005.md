# Visual Discovery Batch 005 — Marlborough Street and Exchange Court

**Date:** 27 October 2026  
**Project:** CICAN DUBLIN  
**Method:** Live catalogue reconciliation; targeted search of the National Inventory of Architectural Heritage (NIAH), Wikimedia Commons, National Library of Ireland and historical Dublin photographic collections.

## Outcome

- No new photograph was added to the visual inventory in this batch.
- No candidate was counted as a location match without both a defensible image-to-object identification and documented reuse permission.
- This is a research-only batch; the catalogue and visual inventory were not changed.
- The latest live inventory audit at the start of this cycle found 195 catalogue records, 195 visual records, 63 records with one or more reference images, 68 image references and 132 records without any reference image. The source registry contains 241 entries.

## Quality-control decision

No generic street image, unrelated building, search-result thumbnail, or copyrighted institutional photograph has been promoted into the inventory. NIAH survey descriptions support identification and research, but do not by themselves grant permission to republish their photographs. NLI catalogue records explicitly identify NLI reproduction rights and therefore remain leads for permission requests, not freely reusable assets.

## Next actions

1. Continue searching exact object names and NIAH registration numbers.
2. Inspect original Commons file pages for candidate photographs and record creator, date, licence and direct image URL.
3. Seek permission from NLI or other rights holders where an image is a strong historical match but not freely reusable.
4. Prioritise exact-object images for the post boxes and individual buildings before adding clearly labelled streetscape context.
5. Re-run the live inventory audit before every subsequent batch; do not use stale README counts as the source of truth.
