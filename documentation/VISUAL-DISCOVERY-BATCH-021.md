## 2. Important separate object: Malahide Road, Artane

NIAH 50130246 is a distinct Edward VII postbox at Malahide Road, Artane, installed c.1905 and made by McDowall, Steven & Co. It is not the c.1940 Jessop Davis box at NIAH 50030291. Official record:
https://www.buildingsofireland.ie/buildings-search/building/50130246/malahide-road-dublin-3-co-dublin

This reinforces the need to use NIAH registration numbers and exact object identity, not street names alone. The Artane box remains outside the existing 195-object catalogue and is not added here.

## 3. New citywide discovery index

A live OpenStreetMap-derived Dublin postbox map reports **577 mapped postbox points** in its extract dated 18 October 2026:
https://wayside.cc/dublin/post-boxes/

This is a valuable discovery index for finding candidate objects and checking catalogue omissions. It is not a photographic archive, does not establish historical identity, and is not an authoritative count of surviving historic boxes. Each candidate still requires exact coordinate, object-type, current existence and image-rights verification.

## 4. Photo search result

This cycle's web search did not surface a new image for the six priority Clontarf / Grand Canal Quay targets with all required evidence (exact object match, accessible original file page, identifiable photographer, explicit reusable licence and location match).

Official NIAH record pages may display gallery images, but the existence of an image on an official record page is not permission to republish it. NIAH photographic terms must be checked separately; the national heritage dataset licence does not automatically license the photographs.
