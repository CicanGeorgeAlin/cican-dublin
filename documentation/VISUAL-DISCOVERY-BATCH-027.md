### DUB-STR-0005 — Four Victorian O’Connell Street bollards
Added a historical image candidate from the National Library of Ireland Wiltshire collection, reference WIL 50[12], 1969. The image shows two ornate pierced cast-iron bollards with foliate caps beside Parnell Monument. The camera position is about 15 metres from the current NIAH point. The image is a strong historical match, but it is not counted as fully verified current-object coverage because continuity between the pictured pair and all four present bollards is not conclusively established. The Commons file page records the NLI Flickr Commons “no known copyright restrictions” statement. Photographer not individually named in file metadata.
