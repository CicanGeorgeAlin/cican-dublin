## Six new catalogue records

1. **DUB-STR-0140 — Malahide Road, Dublin 9** (NIAH 50120064), c.1850 cut-granite pillar with pedimented top; plaque “GPO Dublin 2 Malahide 7”; rear bolt evidence. Irish Grid 318043, 236742.
2. **DUB-STR-0141 — Malahide Road at Belcamp Lane, Dublin 17** (NIAH 50130216), c.1890 cut-granite milestone with triangular top; plaque “GPO Dublin 5 Malahide 4”; recorded in an overgrown roadside margin. Irish Grid 320864, 240445.
3. **DUB-STR-0142 — Malahide Road, Artane** (NIAH 50130243), c.1820 granite milestone with pointed head, angle-headed cast-iron plaque “GPO Dublin 3 / Malahide 6”, and a distinctive rendered surround. Irish Grid 319068, 238039.
4. **DUB-STR-0143 — Dublin Road, Auburn, Malahide** (NIAH 11344043), c.1850 freestanding cast-iron milestone in a cut-granite surround; inscription “GPO/Dublin/8/Malahide/1”. Irish Grid 321318, 245055.
5. **DUB-STR-0144 — Dublin Road, Burrow, Sutton** (NIAH 11358047), c.1850 cast-iron milestone in a granite surround, with benchmark; inscription “P.O/Dublin/7/Howth/2”. Irish Grid 324918, 239225.
6. **DUB-STR-0145 — Howth Road, Dublin 3** (NIAH 50120131), c.1850 cut-granite milestone with pedimented cap; plaque “P.O. Dublin 2 Howth 7”. Irish Grid 318204, 236475.

## Historical interpretation

These records extend the investigation from earlier c.1820–1825 Howth markers to later nineteenth-century milestones on Malahide Road, Dublin Road and the Sutton approach. The inscriptions show distances measured from the GPO and/or to Malahide or Howth. Dublin City Council’s historical account describes the wider Dublin GPO-distance marker tradition and explains that these roadside markers served travellers before modern navigation.

## Coordinate and fieldwork controls

Each published NIAH Irish Grid reference was transformed from TM65 / Irish Grid (EPSG:29902) to WGS84 using EPSG operation 1641. The source grid reference is preserved in every object record. **All six WGS84 points are source-derived, not founder GPS.** Current presence, condition, exact micro-position and safe public access remain to be field-verified. In particular, the Belcamp Lane marker is described by NIAH as being in an overgrown roadside margin; no unsafe access is recommended.
